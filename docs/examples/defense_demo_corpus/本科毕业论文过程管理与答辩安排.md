# 本科毕业论文过程管理与答辩安排

## 一、过程阶段

本科毕业论文工作一般包括选题、任务书、开题报告、中期检查、论文撰写、重复率检测、评阅、答辩和归档等阶段。学生应按照学院发布的时间表完成各阶段任务。

指导教师应对学生选题方向、研究方法、论文结构和学术规范进行指导，并在系统中确认关键节点。

## 二、中期检查

中期检查重点关注论文进度、资料收集、系统实现或实验进展、存在问题和后续计划。学生通常需要提交中期检查表、阶段性论文初稿、系统运行截图或实验记录。

中期检查未通过的学生，应根据学院意见限期整改。整改后仍不能满足要求的，学院可调整答辩资格审核安排。

## 三、重复率检测

论文提交答辩前应进行重复率检测。检测稿应与拟送审论文内容基本一致，不得故意删除正文、图表、参考文献或附录来规避检测。

重复率超过学院规定标准的，学生应按要求修改后重新提交。具体标准以学院当年毕业论文工作通知为准。

## 四、答辩材料

学生参加答辩前应提交论文定稿、查重报告、指导教师评阅意见、评阅教师意见、系统演示材料和必要的附件。涉及软件系统实现的课题，应准备可运行环境、演示账号、测试数据和关键截图。

答辩汇报应重点说明研究背景、需求分析、系统设计、核心实现、测试结果和不足展望。

## 五、归档要求

答辩通过后，学生应按照学院要求提交论文终稿、源代码、系统说明文档和相关过程材料。电子材料命名应清晰，确保后续复核时能够找到对应版本。
