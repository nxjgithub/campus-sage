# CampusSage 答辩演示原始数据与使用流程

本文档用于毕业设计答辩演示，目标是准备一套可复现的原始语料、评测问题和演示话术。演示重点不是“让大模型自由聊天”，而是证明 CampusSage 能完成文档入库、分块预览、知识库问答、引用展示、拒答、反馈和评测闭环。

## 1. 原始数据包

演示语料目录：

`docs/examples/defense_demo_corpus/`

配套评测集：

`docs/examples/eval_set_defense_demo_v1.json`

建议知识库名称：

`CampusSage答辩演示知识库`

建议知识库配置：

| 配置项 | 建议值 | 说明 |
| --- | --- | --- |
| visibility | internal | 答辩演示使用登录账号访问 |
| topk | 5 | 兼顾召回和上下文长度 |
| threshold | 0.25 | 用于基础相似度过滤 |
| rerank_enabled | true | 展示标题、章节路径和关键词覆盖重排效果 |
| max_context_tokens | 3000 | 避免上下文过长 |
| min_evidence_chunks | 1 | 至少需要一个证据片段 |
| min_context_chars | 20 | 过滤过短上下文 |
| min_keyword_coverage | 0.3 | 辅助拒答判断 |

## 3. 导入数据

后端启动后，使用仓库本地虚拟环境执行导入脚本：

```powershell
.\.venv\Scripts\python.exe scripts/bootstrap_demo_academic_kb.py `
  --base-url http://127.0.0.1:8010 `
  --email admin@example.com `
  --password Admin1234 `
  --kb-name CampusSage答辩演示知识库 `
  --corpus-dir docs/examples/defense_demo_corpus `
  --visibility internal `
  --wait-timeout-s 240
```

脚本会完成登录、创建知识库、上传语料、等待入库任务完成，并在控制台输出 `kb_id`、`doc_id` 和 `job_id`。后续评测和接口演示需要记录这个 `kb_id`。

如果管理员账号不存在，先执行：

```powershell
.\.venv\Scripts\python.exe scripts/create_admin.py --email admin@example.com --password Admin1234
```

## 4. 标准演示流程

### 4.1 登录与知识库配置

1. 打开前端页面。
2. 使用 `admin@example.com / Admin1234` 登录。
3. 进入知识库管理页面。
4. 展示 `CampusSage答辩演示知识库` 的名称、描述、可见性和 RAG 参数。

说明口径：

“知识库是系统控制检索范围和 RAG 参数的基本单元。用户提问时，后端会将 `kb_id` 转成向量库过滤条件，避免不同业务资料混入同一次回答。”

### 4.2 文档上传、解析和分块预览

1. 进入文档管理或上传页面。
2. 上传一份 Markdown 文档，例如 `2026届毕业生一次性求职创业补贴申请通知.md`。
3. 展示解析结果、chunk 内容、章节路径和启用状态。
4. 确认入库，等待任务状态变为 `succeeded`。

说明口径：

“系统不是把文件直接交给大模型，而是先解析、分块、生成 embedding，并把 `doc_name`、`section_path`、`chunk_id` 和原文片段写入 payload。后续引用展示依赖这些元数据。”

### 4.3 正常问答与引用展示

推荐问题：

```text
2026届毕业生一次性求职创业补贴需要提交哪些材料？
```

预期表现：

- `refusal=false`
- 回答包含申请明细表、学院盖章纸质文档、困难类别证明等内容
- 引用列表中出现 `2026届毕业生一次性求职创业补贴申请通知.md`
- 引用片段能看到“申请材料”相关内容

说明口径：

“这里展示的是证据驱动回答。答案不是单独的一段文本，而是和引用列表绑定，用户可以回到原始文档核验。”

### 4.4 时效信息问答

推荐问题：

```text
2026届毕业生求职创业补贴个人申请截止到哪一天？
```

预期表现：

- 回答应给出 `2026 年 5 月 20 日`
- 引用应命中文档中的“时间安排”部分
- 如果系统有时效提示，应提醒以学校最新通知为准

说明口径：

“校园政策经常按年份变化，所以系统需要保留 `doc_version`、发布时间和来源信息。即使能回答，也应鼓励用户核验官方最新通知。”

### 4.5 多业务问题

推荐问题：

```text
同一学期建议重修课程总学分不超过多少？
```

预期表现：

- 回答应给出“不超过 12 学分”
- 引用应命中 `2025-2026学年重补修与补考确认通知.md`

推荐问题：

```text
自助打印终端支持哪些登录方式？
```

预期表现：

- 回答应包含校园卡刷卡、学号密码登录、手机验证码登录
- 引用应命中 `校园自助打印与证明材料办理指南.md`

说明口径：

“同一知识库中可以包含多个业务主题，系统通过向量检索和重排把问题路由到最相关的文档片段。”

### 4.6 证据不足拒答

推荐问题：

```text
学校食堂今天午餐有哪些菜？
```

预期表现：

- `refusal=true`
- 不编造菜单
- 给出下一步建议，例如补充食堂菜单数据或查询官方渠道

说明口径：

“拒答是本系统的正常业务状态。对于没有入库的事实，系统宁可提示证据不足，也不能为了流畅而编造。”

### 4.7 边界问题

推荐问题：

```text
申请材料和办理时间能否一起说明？
```

预期表现：

- 系统可能需要结合多个片段回答
- 若证据覆盖不足，应提示补充业务对象，例如是补贴申请、留校申请还是补修申请

说明口径：

“这类问题用于展示系统边界。问题缺少业务对象时，系统应优先澄清或依据已检索证据谨慎回答。”

### 4.8 反馈与会话追溯

1. 对一次回答点击点赞或点踩。
2. 填写反馈原因，例如“引用准确”或“答案不完整”。
3. 展示历史会话和反馈记录。

说明口径：

“反馈不是简单满意度统计，它可以关联到问题、答案、引用证据、检索参数和 request_id，后续可沉淀为评测样本。”

### 4.9 评测运行

记录导入脚本输出的 `kb_id` 后执行：

```powershell
.\.venv\Scripts\python.exe scripts/run_eval.py `
  --base-url http://127.0.0.1:8010 `
  --kb-id <替换为导入脚本输出的kb_id> `
  --eval-file docs/examples/eval_set_defense_demo_v1.json `
  --topk 5
```

展示指标：

- Recall@K
- MRR
- 平均检索耗时
- P95 检索耗时
- 是否命中标准文档

说明口径：

“评测模块把主观演示转化为固定样本上的指标。调整 TopK、threshold 或 rerank 后，可以用同一批问题比较效果。”

## 5. 答辩推荐问题清单

| 场景 | 问题 | 预期 |
| --- | --- | --- |
| 正常问答 | 2026届毕业生一次性求职创业补贴需要提交哪些材料？ | 返回材料清单并引用补贴通知 |
| 时间信息 | 2026届毕业生求职创业补贴个人申请截止到哪一天？ | 返回 2026 年 5 月 20 日 |
| 教务规则 | 同一学期建议重修课程总学分不超过多少？ | 返回不超过 12 学分 |
| 宿舍管理 | 暑假留校学生个人申请时间是什么时候？ | 返回 2026 年 6 月 10 日至 6 月 18 日 |
| 打印服务 | 自助打印终端支持哪些登录方式？ | 返回校园卡、学号密码、手机验证码 |
| 交通管理 | 校园电动车可以带入宿舍充电吗？ | 明确不可以，并引用规定 |
| 论文答辩 | 软件系统实现类课题答辩前应准备哪些材料？ | 返回可运行环境、演示账号、测试数据、关键截图等 |
| 拒答 | 学校食堂今天午餐有哪些菜？ | 证据不足拒答 |
| 拒答 | 明天成都到北京的机票多少钱？ | 超出知识库范围拒答 |
